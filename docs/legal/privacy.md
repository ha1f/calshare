# calshare プライバシーポリシー

このプライバシーポリシー（以下「本ポリシー」といいます）は、calshare（以下「本サービス」といいます）における利用者情報の取り扱いについて定めるものです。

## 第1条（本ポリシーの適用範囲）

本ポリシーは、本サービスの提供にあたって運営者が取得・保存する情報（本サービスが自ら生成する情報に限ります）に適用されます。本サービスは、Cloudflare, Inc.（以下「Cloudflare社」といいます）の提供する基盤の上で稼働しており、同社が基盤運用のために取得するアクセスログ等（プラットフォームレベルのログ）は、本ポリシーの対象外です。

## 第2条（取得する情報）

本サービスは、次の情報を取得・保存します。

1. **予定ページの内容**: 利用者が入力したタイトル・日時・場所・メモ、および作成時の入力全文。これらは、推測が極めて困難なURLを知る誰もが閲覧できる公開情報として保存・公開されるものであり、秘匿情報として扱われません。氏名・住所・電話番号等を入力しないようご注意ください。
2. **IPアドレスのハッシュ値**: 秘密鍵を用いてIPアドレスを不可逆にハッシュ化（HMAC）した値。元のIPアドレスそのものは保存しません。予定ページの作成時に、当該ページに紐づけて保存します（通報時の扱いは第4号のとおりです）。また、予定ページの作成または通報のリクエストを受けた際には、作成・通報が成立したかどうかにかかわらず、レート制限のための回数の記録（第6条3項）として、予定ページとは紐づけずに保存します。
3. **端末識別用Cookie**: 予定ページを作成する操作を行った際に発行する、端末を識別するためのCookie（`cs_device`、有効期間400日）。予定ページの閲覧のみを行った場合、このCookieは発行されません。Cookieの値は、予定ページの作成時に当該ページに紐づけて保存します。また、予定ページの作成のリクエストを受けた際には、作成が成立したかどうかにかかわらず、レート制限のための回数の記録（第6条3項）として、予定ページとは紐づけずに保存します。
4. **通報に関する情報**: 通報理由、任意のコメント（500文字まで）、通報者のIPアドレスのハッシュ値。
5. **アクセスログ**: リクエストのルート名・メソッド・ステータスコード・所要時間、対象の予定ページID、作成の流入元の種別、レート制限超過時の種別、エラーの名称とメッセージ（200文字まで）。生のIPアドレス、IPアドレスのハッシュ値、端末識別用Cookieの値、User-Agent文字列、クエリ文字列全体、予定ページの本文内容、編集トークンは、アクセスログには記録しません。
6. **変更前の日時**: 予定ページの編集によりタイトル・日時・場所のいずれかが変更された場合、変更前の日時を一時的に保持します。詳細ページに変更があったことを示すバナーの表示に用います。

## 第3条（利用目的）

取得した情報は、次の目的に利用します。

1. 予定ページの生成・表示・カレンダー連携（ics生成等）の提供
2. レート制限・スパム対策・不正利用の検知および対応
3. 通報への対応
4. 不具合の調査
5. 個人を特定しない形での統計（作成数、流入元別の集計等）の作成

## 第4条（Cookie・端末情報）

1. `cs_device` Cookieは、レート制限（同一端末からの短時間・大量の作成を制限するため）、および不正利用への対応（同一の送信元から作成された予定ページの特定と一括での非表示）に利用します。広告目的のトラッキングには利用しません。
2. 編集トークンは、作成に使用したブラウザのlocalStorage（端末内のブラウザ保存領域）に保存され、運営者のサーバには送信時にハッシュ化した値のみを保存します。生の編集トークンをサーバに保存することはありません。

## 第5条（第三者への提供・委託）

1. 本サービスは、ホスティング・データベース・オブジェクトストレージの提供のため、Cloudflare社のサービス（Workers・D1・R2）を利用しています。取得した情報は、同社の提供するグローバルネットワーク上（日本国外を含みます）に保存されることがあります。
2. 通報を受理した場合、通報内容の要約（対象の予定ページのURL、通報理由、累計通報件数、同一送信元による有効な予定ページ数、およびコメントを200文字に切り詰めた上でURLを置換したもの）を、運営者があらかじめ設定したDiscordまたはSlackのIncoming Webhook宛てに自動送信します。Webhook宛先の選定・管理は運営者の裁量によります。
3. 前2項のほか、法令に基づく場合を除き、取得した情報を第三者に提供することはありません。

## 第6条（保存期間・削除）

1. 予定ページの内容（タイトル・日時・場所・メモ等）は、[利用規約](./terms.md) 第6条に定める保持期限の経過後、日次の削除処理により削除されます。
2. 通報に関する情報は、対象の予定ページが前項により削除された場合、これに連動して削除されます。
3. レート制限のために保存する回数の記録（IPアドレスのハッシュ値または端末識別用Cookieの値と、1時間または1日ごとの回数）は、集計の単位（1時間または1日）の開始から2日以上経過したものを日次の処理で削除します。このため、最後のリクエストから最大でおよそ3日間保存されます。
4. IPアドレスのハッシュ値・端末識別用Cookieの値は、レート制限・通報対応に用いる目的の範囲でのみ保存します。予定ページまたは通報に紐づけて保存したものは予定ページの削除に伴って削除され、レート制限のために保存したものは前項の処理により削除されます。
5. アクセスログ（第2条5号）の保存期間は、本サービスが利用するログ基盤（Cloudflareのプラットフォーム機能）の保持設定によります。運営者が独自の保存期間を設けているわけではありません。
6. 変更前の日時（第2条6号）は、変更から48時間が経過した後の日次の削除処理で削除されます。このため、変更から最大でおよそ72時間保存されます。詳細ページのバナーは、変更から48時間を過ぎると表示されなくなります。

## 第7条（開示・訂正・利用停止等の請求）

1. 本サービスは、通報フォーム（[通報ポリシー・禁止事項](./report-policy.md)）以外のお問い合わせ窓口を設けていません。
2. 利用者ご自身が作成した予定ページの内容は、作成に使用した端末・ブラウザから編集機能を用いて訂正・削除（内容を空にする等）ができます。編集トークンを失った場合や別端末からの請求については、個別の対応窓口を設けていません。
3. 前2項のとおり、開示・訂正・利用停止等の個別のご請求に対応する窓口は用意していません。この点は運営体制上の制約であり、ご了承の上でご利用ください。

## 第8条（ホスティング環境）

本サービスは、Cloudflare社の提供するWorkers（実行環境）・D1（データベース）・R2（オブジェクトストレージ）上で運用されています。データの保存場所・可用性は同社のサービス仕様に依存します。

## 第9条（未成年の利用者情報）

本サービスは年齢確認の仕組みを設けていないため、未成年の方が入力した情報も、他の利用者と同様に本ポリシーに従って取り扱われます。未成年の方は、保護者の同意を得た上でご利用ください。

## 第10条（本ポリシーの変更）

運営者は、必要と判断した場合、本ポリシーを変更できるものとします。変更後の内容は、本サービス上に掲載した時点から効力を生じるものとし、変更内容は本ポリシー末尾の変更履歴に記録します。

## 第11条（お問い合わせ）

本サービスは、[通報ポリシー・禁止事項](./report-policy.md) に定める通報フォーム以外のお問い合わせ窓口を設けていません。
